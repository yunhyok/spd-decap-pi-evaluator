## 3. 결론

- **`backend.py`의 `ir_steps` 기본값(1)을 바꾸지 않는다.** PCB 케이스가 k≤4에서 1e-8 계약을
  만족시키지 못하므로(§1), "k≤4이고 주파수별 추가 solve 시간 ≤25%"라는 채택 조건 자체가
  성립하지 않는다(참고로 시간 조건만 보면 k=2가 +7.6%로 여유 있으나, 정확도 조건을 못 채운다).
- **GPU 계약을 주파수로 좁혀야 한다(W5/W8 영역, 이번 세션에서는 수치를 확정만 하고 코드는 손대지
  않음): PCB(s5m6585, `Backend(solver="cudss", fast=True)`)에서 1e-8 계약은 1.0 MHz 이상에서
  성립한다.** 1.0 MHz 미만 구간(특히 100 kHz 부근)은 CPU(splu, 9.4e-11)를 쓰거나 별도 완화가
  필요하다.
- 코드 변경 없음: `src/spd_pi_engine/backend.py`는 이번 세션에서 수정하지 않았다.
