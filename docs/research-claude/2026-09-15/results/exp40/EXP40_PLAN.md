# EXP-40 계획 — build 가속 3단계: 규칙 격자용 스캔라인 점-포함 판정 (물리 변경 없음)

작성 2026-09-18, 실행 전 사전 등록. EXP-39가 확정한 병목: `exp1/model.rasterize`가 프리미티브마다 `matplotlib.path.Path.contains_points`(C++ `point_in_path_impl`, O(점 수 × 정점 수))를 부르는데, 260729의 평면 외곽 다각형 하나가 정점 102,456개라 P18 build 395 s 중 338 s가 그 다각형 4회 평가다. 셀 중심은 규칙 격자이므로 다각형을 행(y) 단위로 한 번 훑어 교차 x를 구하면 O(행 수 × 정점 수 + 점 수)로 같은 판정을 낼 수 있다.

## 1. 규칙(고정)
- 물리·수치 정의 불변. 기본 경로(`MplPath.contains_points`) 바이트 단위 불변. 가속은 `SPD_PI_FAST=1`에 붙인다.
- 새 판정은 matplotlib의 규칙을 **재현**한다: `_path.h` `point_in_path_impl`의 교차 판정(부등호의 엄격/비엄격, 교차 x의 계산식과 부동소수 연산 순서, 다중 서브패스·닫힘 처리)을 그대로 옮긴다. 원 프리미티브는 기존 식 그대로 둔다.
- 적용 범위: 정점 수 ≥ V0(예: 64)인 다각형만 스캔라인으로, 그 이하는 기존 호출을 유지해도 된다(정확성에 영향 없음, 단순화). V0는 결과를 보고 조정하지 않는다(속도 파라미터일 뿐 물리 무관).

## 2. 판정 기준(동결)
- (a) 정확도: (1) 합성 검사 — 무작위 다각형(볼록/오목/자기교차 포함)과 격자에서 matplotlib 대비 셀 차이 0, 변 위·정점 위 셀을 의도적으로 넣은 경우도 포함. (2) 7케이스 + Port49의 모든 rasterize 요청에서 FAST 마스크와 기본 마스크의 차이 셀 수(EXP-39 `check_masks.py`와 같은 방식) = 0이면 정확 변환으로 채택. 0이 아니면 케이스별 차이 셀 수와 ΔZ(기준선 exp28/p 대비)를 보고, ΔZ ≤ 1e-8이면 "경계 셀 차이 있음"을 명시하고 채택, 초과면 기록만.
- (b) 속도: 같은 세션 단독 대조로 P18 build ≤ 60 s(EXP-39 361 s), Port49 build ≤ 5 분(17.1 분)이면 성립.
- (c) 기본 경로 불변: `smoke_port18.py` 5.83e-12 PASS, `run11.py --variant p --smoke --smoke-baseline exp28:p` 0.0.
