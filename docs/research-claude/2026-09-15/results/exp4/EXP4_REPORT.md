## A1. 코드 사실

- **식:** `copper_surface_impedance`(`src/spd_decap_pi/_core/solver/mfdm.py:782`)는 `_copper_two_face_terms`(:735)의 self 항 **Zc·coth(γt)**를 반환한다.
  - Zc = (1+j)/(σδ), γ = (1+j)/δ다.
  - docstring대로 **one-face(한쪽 면 귀환)** 식이다.
- **저주파 극한:** 1/(σt) + jωμ0·t/3이다. 수치로 확인했다.
  - 20 µm: 0.839 mΩ/□, **8.38 pH/□**
  - 32 µm: 0.524 mΩ/□, **13.40 pH/□** (10 MHz에서 11.8 pH/□로 감소)
- **적용 위치(EXP-3):**
  - 레일 평면 edge: `model3.py:452`(`edge_z`), 복소 Zs를 R 항에 넣는다
  - 명시 GND 시트 edge(S3): 같은 함수, 복소
  - off-plane 레일 trace: `:486`, `:533`
  - via는 R만 쓴다(Zs 미사용).
- 1b의 `exp1/model.py:508,531`도 같다.
- **결론:** 외부 L은 양측 d_eff인데 내부 L은 한쪽 귀환(μ0t/3)으로 넣었다. 코디네이터의 의심이 **사실**이다.

## A3. 판정

1. **내부 L 과대 계상은 실재하는 모델 결함이다.** 한쪽식의 μ0t/3 때문에 레일 내부 L이 저주파에서 약 8 pH(L25 5.0 + L14 2.8 + L21 0.2) 들어가 있었다.
   - 이 성분은 표피효과로 줄어든다(L25 13.4→11.8 pH/□). 따라서 ΔL(f)의 "상수 → 감소" 형태 중 **약 40%(19→11 pH)를 설명한다.**
2. **물리적으로 옳은 수정은 (b)다.** 양측 귀환에서 내부 L은 0이 아니라 μ0t/12다.
   - ΔL은 +13.3 pH(100 kHz) → +10.5 pH(1 MHz) → +3.2 pH(2.5 MHz)가 되고, G3는 9.1%로 **통과**한다. 격자에도 견고하다(9.0%).
   - (a)는 가장 잘 맞지만(7.7%), 내부 L=0은 물리적 근거가 없어 채택하지 않는다.
3. **G2는 어느 변형에서도 ±5 pH에 들어오지 않는다.**
   - (b) 이후에도 30–300 kHz에 **+12~14 pH의 거의 일정한 초과**가 남는다. 이 잔차는 2.5 MHz 이상에서 +3~6 pH로 줄어든다.
   - 내부 L 가설로는 형태가 **부분적으로만** 설명된다. 남은 몫은 여전히 L25 외부 경로(29.7 pH)에 몰려 있다.
4. **(c):** GND 시트 R은 전 층 병렬 근사(×6/13)로 +0.05 mΩ다. G1이 0.060으로 경계에서 실패하고, G3는 13.0%로 되돌아간다.
   - GND 망 R(0.011 mΩ)은 스케일하지 않았다. 전 층을 명시하면 G1은 경계 근처일 것이다[추정].
   - 명시 GND를 넣으면 R 초과(+0.085 mΩ @1 MHz)와 L 초과가 함께 남는다. EXP-3의 결론(분배 한 번으로는 둘을 맞출 수 없음)이 유지된다.
5. **G2/G3 동시 통과가 없으므로 사다리를 종료한다.**
   - 채택 모델은 **EXP-3 S2 + (b) 양측 대칭 Zs**다(G1, G3 PASS / G2, G4 FAIL).
   - 참조가 이상 GND에 가깝다고 가정할 때만 G3를 통과한다. 실제 GND R을 넣은 (c)에서는 실패한다. 이 점을 명시한다.
