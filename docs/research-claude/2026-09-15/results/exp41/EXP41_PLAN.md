# EXP-41 계획 — held-out 260804 전 포트 일반화 검증 (동결 기준선 exp28/p, 튜닝 없음)

작성 2026-09-18, 실행 전 사전 등록. §6-5(일반화)의 미실행 항목. 지금까지 260804는 Port18 한 케이스만 열었다. 기준선 p(D7)는 동결돼 있고 EXP-37~40으로 92포트 sweep이 수 분 규모가 됐으므로, 두 번째 패키지 설계의 전 포트를 연다. 결과를 보고 규칙·파라미터를 바꾸지 않는다.

## 1. 규칙(고정)
- 모델: 변형 p(`c_unit_fix, homog_face_fix`) 그대로. 실행 플래그 `SPD_PI_SOLVER=cudss SPD_PI_FAST=1`(정확 변환·GPU 경로; CPU 대비 ΔZ ≤ 1e-8은 EXP-37~40에서 검증됨).
- 러너 `exp15/runall15.py --tag 260804 --variant p --outdir exp41`, 집계 `summary15.py --dir exp41 --variant p --tag 260804`, 포트별 비교는 260729의 exp28/p 결과와 **같은 포트 이름끼리** 대조(두 설계는 같은 제품 계열의 리비전이므로 포트 이름이 대응된다고 가정; 대응되지 않는 포트는 표에서 제외하고 개수를 보고).

## 2. 사전 예측
- 260729 92포트(p): G3 PASS 22/92, err_1MHz 중앙값 31.7 %, R 비(Re Z_ref/Re Z_model @100 kHz) 중앙값 1.46. 같은 패키지 급전 구조이므로 260804도 같은 자릿수(G3 PASS 15–30/92, R 비 1.3–1.6)로 예측한다. 리비전 간 차이(EXP-5의 260804 P18 4.9 % 대 260729 2.69 %)가 있으므로 포트별 err의 상관은 ρ ≥ 0.7로 예측한다.
- 이 예측이 맞으면 "R 결손은 설계 개별 특성이 아니라 패키지 급전 구조 관례 차이"라는 EXP-31 해석이 강화된다. 260804가 260729보다 뚜렷이 좋거나 나쁘면(G3 PASS 차이 > 15) 리비전 간 어떤 구조가 다른지 기록만 한다.
