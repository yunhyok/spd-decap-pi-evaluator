# EXP-33 계획 — 직렬 공진 f_res 편향의 분해: ΔC(저주파)와 ΔL(고주파), 패키지(260729/p) vs PCB(s5m6585/p) (자료만, 모델 실행 없음)

작성 2026-09-17, 실행 전 사전 등록. G4(f_res ±10 %)는 두 설계 모두 전 포트 FAIL이다. PCB에서는 모델 f_res가 참조보다 9–16 % 높고(레일별 중앙값), 패키지 P18/804-P18에서는 15 % 낮다. 방향이 설계마다 다르므로 L과 C 중 어느 쪽이 어긋나는지 분해한다. 파라미터 변경 없음.

## 1. 정의(동결)
- 각 포트: C_eff = −1/(2πf·Im Z) at f = 100 kHz(모델·참조), L_eff = Im Z/(2πf) at f = 10 MHz 최근접 사다리점(모델·참조; 직렬 공진 위·반공진 아래여야 함 — f_res_ref < 5 MHz이고 10 MHz에서 Im Z_ref > 0인 포트만 대상).
- 비 r_C = C_mod/C_ref, r_L = L_mod/L_ref, r_f = f_res,mod/f_res,ref. 검증: r_f ≈ (r_L·r_C)^(−1/2) 를 각 포트에서 확인(20 % 이내면 분해가 유효).
- 설계별 집계: r_C·r_L의 중앙값과 사분위. PCB에서는 decap 수 N_d(3–7)를 알고 있으므로 ΔL_abs = L_mod − L_ref와 N_d·ΔL_abs(포트 decap 병렬 수를 곱한 decap당 환산 L)도 낸다.

## 2. 가설(동결)
- H_C: 두 설계 모두 r_C가 0.95–1.05 안(중앙값) → "C는 맞고 f_res 편향은 L에서 온다" 채택.
- H_Lpcb: PCB에서 r_L 중앙값 < 0.85(모델 L 부족)이고 N_d·ΔL_abs 중앙값이 −0.3 ~ −1.5 nH 범위 → "decap 실장 L(§6-4(i)) 미포함" 후보 채택. 이 값은 PCB 0402/0603 decap의 통상 실장 L 범위와 비교하는 것이며 참조에 맞추는 계수가 아니다.
- H_Lpkg: 패키지에서 r_L 중앙값 > 1.1(모델 L 과다) → 패키지의 급전 L(평면·via)이 과다. P18·804-P18의 낮은 f_res와 정합해야 한다.
- 예측: H_C 채택, H_Lpcb 채택, H_Lpkg 채택(설계에 따라 L 오차 부호가 다름 = 서로 다른 두 기구).

## 3. 판정 후 해석(미리 적음)
- H_Lpcb 채택이면 §6-4(i)를 PCB에서 먼저 시험한다: decap당 실장 L을 기하로 정의(패드 중심 간 거리 s, 패드→평면 거리 h로 μ0·h·s/w 급의 폐형식, 자유 계수 없음)해 사전 등록.
- H_Lpkg 채택이면 패키지 급전 L 과다의 위치(평면 L vs via L)를 EXP-31식 회귀(Im 부분)로 좁힌다.
