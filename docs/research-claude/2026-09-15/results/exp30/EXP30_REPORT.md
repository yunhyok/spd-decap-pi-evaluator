# EXP-30 보고서 — held-out 설계 s5m6585(PCB, 160포트) 일반화

실행 2026-09-17, 사전 등록 `EXP30_PLAN.md`(§2 기준 불변; §5에 실행 전 형식 보완 기록). 기준선 exp28/p 규칙(c_unit_fix + homog_face_fix), 160포트 전부 성공(실패 0), CPU 16.4 h, 포트당 최대 710 s·미지수 367k. 형식 보완 두 가지(`_DGND` 층 이름 인식, `xcall/.SUBCKT` decap 모델 fallback)는 260729 결과를 바꾸지 않았다(smoke PASS, 추출 비트 동일).

## 1. 결과

| 지표 (160포트) | s5m6585 (PCB) | 260729 (패키지, exp28/p) |
|---|---|---|
| err_1MHz 중앙값(사분위) | **0.58 % (0.34–1.29)**, 최대 24.9 % | 31.7 % (10.4–38.0) |
| G3 PASS | **128 / 160 (80 %)** | 22 / 92 (24 %) |
| Re Z_ref/Re Z_model @100 kHz 중앙값(사분위) | **1.03 (1.02–1.07)** | 1.46 (1.15–1.58) |
| dRe_100k < −0.05 mΩ 포트 | 160 / 160 (중앙값 −1.4 mΩ) | 76 / 92 (중앙값 −7.8 mΩ) |
| G1 / G2 / G4 PASS | 0 / 0 / 0 | 6 / 12 / 0 |
| f_res 모델/참조 중앙값 | 1.09–1.16(레일별) | (G4 전부 FAIL) |

레일별: ADC_DVDD08_CORE·DVDDQ12·DVDDQ18·AVDD08_LO(각 32포트, decap 3–7개)는 err 중앙값 0.3–1.2 %, G3 32/32, R 비 1.01–1.07. **ADC_IO_BUCK13**(32포트)만 err 22 %, R 비 1.27, G3 0/32 — 이 레일의 decap은 전부 `CAP_2012-NULL_NULL`(빈 모델)이라 모델·참조 모두 bare plane에 가깝고, G3 FAIL 32개가 전부 여기서 나온다.

## 2. 판정
- H_pkg: 비 중앙값 1.03 < 1.15는 충족, 그러나 "dRe_100k < −0.05 mΩ 비율 < 30 %"는 100 %로 불충족 → **형식상 불확정**. 이 절대 문턱(0.05 mΩ)은 패키지 규모용이며 PCB의 100 kHz Re Z(수십 mΩ)에는 부적절했다(계획 설계 결함, 사전 등록 그대로 보고). 규모 무관 지표인 R 비로는 결손이 3 %(PCB) vs 46 %(패키지)로 **패키지 특유**임이 분명하다.
- H_gate: G3 PASS 80 %(예측대로 PCB에서 훨씬 높음). G1·G2는 절대 문턱(0.05 mΩ, 5 pH)이 PCB 규모에 맞지 않아 전부 FAIL이며 해석하지 않는다. G4는 f_res가 9–16 % 높아 FAIL(패키지와 같은 방향).

## 3. 해석
- **채택 모델(p)은 PCB에서 1 MHz 중앙값 0.6 %로 맞는다.** decap이 3–7개뿐인 레일에서도 맞으므로, 260729의 R 결손은 "decap이 적어서"가 아니라 **패키지 급전 구조(20 µm 층·40 µm 충전 microvia 9단 스택·TOP 패드 링크·다수 타넷 평면)**에 특유한 관례 차이다. PCB의 via는 PTH(도금 배럴 모델)이고 이 경로는 맞는다.
- 따라서 후보는 충전 microvia 스택의 R 산정(PowerSI가 microvia를 어떻게 모델링하는지: 도금 두께 기본값, 원추형, 패드 관통 저항)으로 좁혀진다. EXP-31에서 92포트 자료로 요소별 스케일 계수를 회귀해 "어느 요소가 몇 배"인지 정량화한다.
- f_res 편향(+9~16 %)은 PCB에도 있으므로 설계 무관한 모델 공통 문제(L 또는 C 배분)이며 별도 과제다.

파라미터 변경 없음. 게이트 정의 불변(단 G1·G2 절대 문턱은 설계 규모 의존이라는 한계를 기록).
