# EXP-19 계획 — (1) 저주파 R 결손과 고주파 R 부족의 상관, (2) ΔL 지표 재정의 (보유 자료만, 모델 실행 없음)

작성 2026-09-16, 실행 전 사전 등록. 입력은 EXP-15(exp15/j, 92포트)와 EXP-18b(exp18/k2, 92포트) 영수증. 파라미터 변경 없음.

## 1. 정의(동결)
- r_LF = dRe_100k / Re Z_ref(100 kHz): 저주파 상대 R 오차(음수 = 결손).
- r_HF = 10–100 MHz의 (Re Z_model − Re Z_ref)/Re Z_ref 중앙값(EXP-17 정의).
- f_res_ref = 참조 |Z| 최소 주파수(영수증 `f_res_ref`). ΔL(f) = Im(Z_model − Z_ref)/(2πf).
- ΔL_LF = 0.1–1 MHz ΔL 중앙값(EXP-17과 동일). **ΔL_HF′** = f ∈ [2·f_res_ref, 3e7 Hz]의 ΔL 중앙값. D′ = ΔL_HF′ − ΔL_LF. 대상 포트는 f_res_ref ≤ 5 MHz이고 위 구간에 점이 3개 이상인 포트로 제한한다(용량성 소형 레일 제외).

## 2. 가설(동결)
- H_e(같은 기원): 92포트에서 Spearman ρ(r_LF, r_HF) ≥ 0.5(p < 0.01)이면 채택 — 저주파 결손과 고주파 부족이 같은 경로(급전 via·trace의 R 관례)에서 나온다. ρ < 0.2면 기각(원인이 다름), 그 외 불확정. exp15/j와 exp18/k2 양쪽에서 계산하고 j를 주 판정으로 한다.
- H1′(고주파 L 부족, 재정의): 대상 포트에서 D′ < 0 비율 ≥ 0.6이고 중앙값 D′ ≤ −3 pH이면 채택; 비율 < 0.5이거나 중앙값 > 0이면 기각; 그 외 불확정. EXP-17 H1의 기각이 지표 결함(ΔC 흡수) 때문이었는지 판정한다.
- H2′(D′ ~ via L): 대상 포트에서 Spearman ρ(|D′|, via L) ≥ 0.5(p < 0.01) 채택, < 0.2 기각.

## 3. 판정 후 해석(미리 적음)
- H_e 채택이면 §6-3과 §6-6은 한 과제(급전 경로 R의 주파수 의존 관례)로 합쳐 다음 정식화를 등록한다. 기각이면 두 과제를 분리해 진행한다.
- H1′ 채택이면 "고주파 L 부족"이 실재하며 via 귀환 루프(two-wire) 정식화를 저주파를 깨지 않는 형태(예: 주파수 의존이 아닌 decap via 쌍 국소 루프)로 등록한다. 기각이면 고주파 오차는 R 부족(H3)만 다룬다.
