# EXP-18b 계획 — 벽 표피 손실의 실수부만 고주파 전용으로 추가 (k2)

작성 2026-09-16, EXP-18 7케이스 실행 전·k 스모크 후 등록. EXP-18 §1의 규칙 k는 `Zs1(f) − 1/(σt)`의 복소 전체를 더하므로 벽 내부 L(저주파 극한 μ0 t/3 ≈ 8.4 pH/□, 20 µm)이 모든 주파수에 들어간다. P18 스모크에서 1 MHz |ΔZ|/|Z| = 2.6e-2(Im Z −0.4118 → −0.3906 mΩ)로 EXP-18 §2 예측(< 1e-3)을 벗어났고, 그 원인은 표피 R이 아니라 이 내부 L이다(1 MHz 표피 R 증분은 6.5e-6 mΩ/□). EXP-18 §4 (a)는 k에서 성립하지 않을 것이 확실하므로 k는 기록용으로만 돌리고, 손실만 넣는 변형 k2를 별도 등록한다.

## 1. 규칙(고정)
- 변형 k2 = `c_unit_fix=True` + `zs_wall_skin_re=True`: 레일 엣지 Zs에 `Re[Zs1(f; σ_w, t_w) − 1/(σ_w t_w)]`(실수, 표피 R 증분만)를 더한다. 벽 배정·양측 병렬·엣지 평균은 k와 동일. 코드 폐형식 기준 20 µm 구리의 증분 R은 1e5 Hz 6.5e-6, 1e7 Hz 0.056, 1e8 Hz 0.95 mΩ/□(k 스모크 `wall_skin_R_sq_mOhm`; EXP-18 §1의 손계산 0.2/1.7은 과대였다).

## 2. 사전 예측
- ≤ 1 MHz: |ΔZ|/|Z| < 1e-4(증분 R이 1e-5 mΩ/□ 이하), G1·G2·G3 PASS 집합 7케이스 불변.
- 10–100 MHz: ΔR/Re Z_ref(EXP-18 §2 표, 7케이스 중앙값 −0.144)가 0 쪽으로 이동하나, 100 MHz 증분 0.95 mΩ/□는 레일 시트 자체의 표피 R과 같은 자릿수이므로 부족분 25 %의 일부만 메울 것으로 본다(중앙값 절대값 감소 20–50 %).

## 3. 판정 기준(동결) — EXP-18 §4와 동일
- (a) 7케이스 G1·G2·G3 PASS 집합 불변, ≤ 1 MHz max |ΔZ|/|Z| ≤ 1e-3.
- (b) 7케이스 10–100 MHz ΔR/Re Z_ref 중앙값 절대값 30 % 이상 감소.
- (a)(b) 성립 → 92포트 실행(`runall15.py --variant k2 --outdir exp18`), EXP-17 H3 지표 비교(ΔR < 0 비율 ≤ 70 % 또는 중앙값 |ΔR|/Re Z_ref ≤ 0.15면 채택 제안). 그 외 기록만.
- G1–G5 정의 불변.
