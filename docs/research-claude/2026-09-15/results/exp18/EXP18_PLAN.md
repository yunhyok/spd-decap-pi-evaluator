# EXP-18 계획 — 귀환면(벽) 표피 손실을 고주파 전용으로 추가 (§6-6 첫 정식화)

작성 2026-09-16, 실행 전 사전 등록(§4 기준은 결과를 본 뒤 바꾸지 않는다). EXP-17 H3(92포트 중 90에서 10–100 MHz 모델 R 부족, 중앙값 25 %)의 후속. 기준선 exp13/j. 파라미터 튜닝 없음(추가되는 항은 벽 재질·두께에서 정해지는 폐형식이며 자유 계수가 없다).

## 1. 규칙(고정)
- 변형 k = `c_unit_fix=True` + `zs_wall_skin=True`. 레일 엣지 Zs에 귀환면 항 `Zw_skin(f) = Zs1(f; σ_w, t_w) − 1/(σ_w t_w)`를 더한다(복소: 표피 R 증분과 벽 내부 L 모두 포함, DC에서 0). 벽 배정·양측 병렬 합성·엣지 평균 규칙은 EXP-12 (d)와 동일(`Model4.wall_zs`), 다른 점은 DC 항 1/(σt)을 빼는 것뿐이다.
- 20 µm 구리 벽에서 증분 R은 1 MHz(δ ≈ 65 µm) 약 0.001 mΩ/□ 이하, 10 MHz(δ ≈ 21 µm) 약 0.2 mΩ/□, 100 MHz(δ ≈ 6.5 µm) 약 1.7 mΩ/□다.

## 2. 사전 예측
- ≤ 1 MHz: |ΔZ|/|Z| < 1e-3, G1·G2·G3 PASS 집합 7케이스 불변(EXP-12 (d)가 깨뜨린 G1이 보존된다).
- 10–100 MHz: 모델 Re Z가 늘어 ΔR = Re Z_model − Re Z_ref(음수)가 0 쪽으로 이동. 7케이스의 10–100 MHz ΔR/Re Z_ref 중앙값(기준선 exp13/j에서 산출, 실행 전 기록: 아래 표)이 절대값으로 30 % 이상 줄면 예측 확인.

## 3. 방법
1. 플래그 `Model3(zs_wall_skin=False)`; `Model4.wall_zs`에 DC 항 제거 분기. 기본 경로 불변 검증(`--variant none --smoke` ≤ 1e-9, `smoke_port18.py` PASS).
2. `run11.py --variant k` → `WORK_DIR/exp18/`, `table11.py --exp exp18 --baseline exp13:j`. 7케이스 병렬.
3. `dl17.py --dir exp18`로 7케이스의 10–100 MHz ΔR 통계를 기준선과 비교.
4. 7케이스에서 §4의 (a)(b)가 모두 성립하면 92포트 실행(`runall15.py --variant k --outdir exp18`, 약 1.4 h)해 H3 지표(ΔR < 0 비율, 중앙값 |ΔR|/Re Z_ref)를 EXP-17과 비교한다. 성립하지 않으면 92포트는 돌리지 않는다.

## 4. 판정 기준(동결)
- (a) 7케이스 G1·G2·G3 PASS 집합 불변이고 ≤ 1 MHz max |ΔZ|/|Z| ≤ 1e-3.
- (b) 7케이스 10–100 MHz ΔR/Re Z_ref 중앙값의 절대값이 기준선 대비 30 % 이상 감소.
- (a)(b) 성립 → 92포트 실행; 92포트에서 ΔR < 0 비율이 98 %에서 70 % 이하로 내려가거나 중앙값 |ΔR|/Re Z_ref가 0.25에서 0.15 이하로 내려가면 "고주파 손실 정식화 후보로 채택 제안"(소유자 승인 후 기준선 변경). 그 외는 기록만.
- G1–G5 정의 불변. G5는 여전히 보고만.
