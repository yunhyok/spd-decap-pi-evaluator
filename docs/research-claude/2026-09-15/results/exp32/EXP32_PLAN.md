# EXP-32 계획 — via 길이 관례: 층 중심 간 → 층 표면 간 (변형 q), 기준선 exp28/p

작성 2026-09-17, 실행 전 사전 등록. EXP-31에서 결손이 급전 경로(via·trace) R에 있고 평면은 맞음이 확인됐다. 자유 계수 없이 시험 가능한 첫 후보는 via 길이 정의다. 현재 `M3:301` ℓ = |z_center(L_lower) − z_center(L_upper)|(층 중심 간). 대안 = via 배럴이 위층 패드 상면에서 아래층 패드 하면까지 이어진다고 보는 표면 간 길이 ℓ′ = ℓ + (t_upper + t_lower)/2. 20 µm 층·20 µm 유전체의 microvia에서 40 → 60 µm(×1.5), PTH(DR-2128_350, 8층)에서는 ×1.05 정도다.

## 1. 규칙(고정)
- 변형 q = exp28/p 플래그(c_unit_fix, homog_face_fix) + `via_len_surface=True`: 모든 레일 via의 R에 쓰는 길이를 ℓ′로 바꾼다(SOLID·HOLLOW 공통). via L(`ln(sd/(drill/2))` 항)의 길이도 같이 ℓ′로 바꾼다(길이 정의는 하나여야 한다). 패드 링크 불변.
- 이는 관례 정의의 대안이지 참조에 맞춘 계수가 아니다(1.5는 기하에서 나온 값).

## 2. 사전 예측
