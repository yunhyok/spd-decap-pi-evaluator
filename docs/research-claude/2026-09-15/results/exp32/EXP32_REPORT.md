## 3. 판정
- (a) 7케이스 PASS→FAIL 1건(P16 G2) → 불성립. (b) R 비 편차 감소 37 %(문턱 40 %) → 근소 불성립, G3 증가는 성립.
- 동결 규칙: **기록만**. 방향은 예측대로(급전 경로 R 상향이 92포트 오차를 줄임)이나, via 길이 정의 하나(×1.4)로는 결손의 약 1/3만 메운다(비 1.46 → 1.30). 평면 지배 레일에서는 via R 상향이 해가 되므로, 실제 관례 차이가 "모든 via ×1.4"는 아니다 — 스택 via(microvia 9단)에 국한된 요소(패드 관통·랜딩 접속 R)일 가능성이 남는다.
- 기준선은 exp28/p 유지. G1–G5 정의 불변.
