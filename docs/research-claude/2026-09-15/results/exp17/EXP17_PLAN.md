# EXP-17 계획 — 10–100 MHz 오차의 주파수 구조 진단: ΔL(f)·ΔR(f) 스펙트럼 (보유 자료만, 모델 실행 없음)

작성 2026-09-16, EXP-15 결과를 보기 전에 등록. 인계 §6-6의 착수 단계. EXP-14 (h)에서 via L 2배가 저주파 G2를 깨면서 G5(10–100 MHz)를 개선한 단서를 정량화한다. 모델 파라미터는 바꾸지 않는다.

## 1. 입력
EXP-15 92포트 영수증(기준선 exp13/j): 사다리 + 0.3–30 MHz 21점 dense grid의 Z_model, Z_ref. 추가로 EXP-14 (h) 7케이스 영수증.

## 2. 정의(동결)
- ΔL(f) = Im(Z_model − Z_ref)/(2πf) [pH], ΔR(f) = Re(Z_model − Z_ref) [mΩ], 포트별 사다리 전 주파수.
- 저주파 기준 ΔL_LF = 0.1–1 MHz의 ΔL 중앙값(G2 fit 구간), 고주파 ΔL_HF = 10–30 MHz의 ΔL 중앙값(dense grid, 공진 위). 차이 D = ΔL_HF − ΔL_LF.
- 반공진 영역(|Z|가 국소 최대인 9–15 MHz)은 ΔL 정의가 불안정하므로 |Z| 비율(|Z_model|/|Z_ref|)로 따로 본다.

## 3. 가설(동결)
- H1(고주파 L 부족): D < 0인 포트가 과반(≥ 60 %)이고, D의 중앙값이 −3 pH 이하다. 즉 모델 L은 저주파에서 맞고 고주파로 갈수록 부족하다.
- H2(via L 규모): |D|의 중앙값이 EXP-14 계획 §2 표의 via L(P18 5.3 pH, 7케이스 1.6–309 pH)과 같은 자릿수이고, 포트별 |D|와 via L(100 kHz breakdown)의 Spearman ρ ≥ 0.5다. 성립하면 (h)의 G5 개선은 via 귀환 루프의 고주파 확대와 정합한다.
- H3(손실 부족): ΔR(f)가 10–100 MHz에서 음(모델 R 부족)인 포트가 과반이고, |ΔR|/Re Z_ref의 중앙값이 20 % 이상이다(GND 손실·표피효과 미포함의 서명).

## 4. 판정 기준(동결)
각 가설을 채택/기각/불확정으로 보고한다(수치 문턱은 §3). H1·H2 채택이면 §6-6의 다음 단계로 "주파수 의존 via 귀환 반경" 대신 **물리 근거가 있는 정식화 후보**(decap via 쌍의 two-wire L + 평면 귀환 전류 집중)를 별도 사전 등록한다. H3 채택이면 GND 시트 손실을 G1을 깨지 않는 형태(고주파에서만 커지는 표피 R)로 넣는 후보를 등록한다. 어느 결과든 이번 실험에서 파라미터를 바꾸지 않는다.
