# EXP-23 계획 — 1–30 MHz 공진 구조 비교: 직렬 공진과 반공진의 위치·높이·폭 (92포트 자료만, 모델 실행 없음)

작성 2026-09-17, 실행 전 사전 등록. EXP-22(모델 유효 L이 5–30 MHz에서 요동)와 G4 전 포트 FAIL의 원인을 공진 구조 수준에서 기술한다. 파라미터 변경 없음.

## 1. 정의(동결)
- 영수증 exp15/j(기준선)와 exp20/mk(표피 항 포함)의 사다리(0.3–30 MHz 21점 dense + 사다리 점) 위에서 |Z_model|, |Z_ref|.
- 직렬 공진 f_s: 1–10 MHz 구간 |Z| 최소점(영수증 f_res). 반공진 f_a: f_s 위 3–30 MHz 구간의 |Z| 국소 최대점(모델·참조 각각). 높이 |Z(f_a)|, 폭 W = f_a에서 |Z|가 최대의 1/√2로 내려오는 양측 주파수 간격(사다리 해상도 한계로 log 보간).
- 지표: 위치비 f_a,mod/f_a,ref, 높이비 |Z_a,mod|/|Z_a,ref|, 폭비 W_mod/W_ref, f_s 위치비(기존 G4 f_res 지표).
- 대상: f_s,ref ≤ 5 MHz이고 3–30 MHz에 국소 최대가 양쪽에 존재하는 포트.

## 2. 가설(동결)
- H_pos: f_a 위치비 중앙값이 0.9–1.1 안에 있으면 "반공진 위치는 맞음" 채택; 밖이면 기각(어느 방향인지 보고).
- H_h: 높이비 중앙값 > 1.15이면 "모델 반공진이 과대(감쇠 부족)" 채택; < 0.87이면 "과소"; 사이면 불확정.
- H_w: 폭비 중앙값 < 0.85이면 "모델 반공진이 좁음(Q 과대)" 채택; > 1.15면 넓음; 사이면 불확정.
- H_skin: exp20/mk에서 높이비·폭비가 참조 쪽으로 이동(높이비 중앙값 절대편차 20 % 이상 감소)하면 표피 항이 반공진 감쇠에 기여한다고 판정.
- 예측: H_pos 채택(위치는 대체로 맞음), H_h "과대" 채택, H_w "좁음" 채택, H_skin 소폭 기여(20 % 미만, 불충족).

## 3. 판정 후 해석(미리 적음)
- H_h·H_w 채택이면 문제는 반공진 감쇠(손실)이며 위치(L·C)는 아니다 → §6-6의 정식화 방향을 "손실"로 고정(급전 경로 R 관례 + 표피 항). 위치 오차가 크면 L·C 배분(평면 C 단위 수정 이후 남은 plane/via L)이 문제.
