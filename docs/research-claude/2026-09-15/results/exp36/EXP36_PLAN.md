# EXP-36 계획 — PowerSI "Special Void" 설정(1500 µm 미만 구멍 제외)을 모델에 반영 (변형 pv), 기준선 exp28/p

작성 2026-09-17, 실행 전 사전 등록. 소유자 제공 PowerSI 옵션 화면(Simulation (Basic) → Special Void): Dogleg/Thermal/Other/Via hole smaller than **1500 µm**는 시뮬레이션에서 제외(= 금속으로 채움), slender hole 0. 이는 참조가 평면의 via 구멍·anti-pad를 전부 채운 상태로 계산됐다는 뜻이며, 모델은 export된 void를 그대로 쓴다(EXP-6 V0). EXP-6에서 같은 실험을 했으나 그때는 평면 C 단위 오류와 균질화 결함이 있었으므로 p 위에서 다시 판정한다. 관례 일치 실험이며 자유 계수는 PowerSI 설정값(1500 µm)뿐이다.

## 1. 규칙(고정)
- 변형 pv = p 플래그 + `void_fill_um=1500`: 레일 평면 artwork의 음(陰) 형상(neg_polys, neg_circles) 중 외접 크기(원: 지름, 다각형: bbox 최대변)가 1500 µm 미만인 것을 래스터화 전에 제거한다(EXP-6 `run6.py --dmax`와 같은 규칙; 슬렌더 홀 기준 0 → 미적용). 기준면(벽) 검색용 shape에는 적용하지 않는다(기준면은 이상 도체이므로 무관).
- 이 규칙은 PowerSI 설정을 그대로 옮긴 것이며 결과를 보고 값을 조정하지 않는다.

## 2. 사전 예측
- EXP-6(j 이전 기준선)에서는 채움이 평면 R을 낮춰 참조와 더 멀어졌다(ΔRe −0.13 ~ −0.96 mΩ). p 위에서도 같은 방향(모델 R 감소, R 결손 확대)이 예상된다. 즉 이 관례 차이는 R 결손의 원인이 아니라 오히려 결손을 더 키우는 방향임을 확인하는 실험이다. L은 소폭 감소(ΔL −1 ~ −5 pH).
- 7케이스 게이트: P18의 G1(0.007 mΩ 여유 0.043)은 유지, 나머지 변화 없음 예측.

## 3. 판정 기준(동결)
- 관례 일치가 목적이므로 채택 기준은 "참조와의 일치"가 아니라 "PowerSI 설정 재현"이다. 따라서 (a) 7케이스 PASS→FAIL 없음이면 pv를 **관례 일치 플래그로 기록**하고, 92포트 R 비 중앙값의 변화(1.46 → ?)를 보고한다. 기준선 변경은 하지 않는다(소유자 판단: PowerSI 관례를 따를지, 물리 void를 유지할지 — 제품의 "PowerSI-compatible" 모드(D5)에 넣을 후보).
- 92포트는 7케이스 결과와 무관하게 실행한다.
