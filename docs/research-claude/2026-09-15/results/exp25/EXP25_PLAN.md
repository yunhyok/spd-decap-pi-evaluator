# EXP-25 계획 — 어긋난 쌍둥이 쌍의 모델 급전 경로 R 요소별 분해 (영수증·extract만, 모델 실행 없음)

작성 2026-09-17, 실행 전 사전 등록. EXP-24에서 참조는 사이트 대칭(s_ref ≈ 1)인데 모델 R이 2배 이상 갈리는 4-decap 레일 쌍(k = 19, 27, 35, 12, 11, 38)이 나왔다. 사이트 차이가 모델의 어느 요소에서 나오는지 특정한다. 파라미터 변경 없음.

## 1. 정의(동결)
- 대상: |ln(s_mod/s_ref)| 상위 8쌍(EXP-24 `exp24.json`) + 대조군으로 모델·참조 비대칭이 10 % 안에서 일치하는 쌍 중 decap ≤ 10인 쌍 4개.
- 요소별 R(100 kHz, exp15/j 영수증 `breakdown_100k`): 평면 층별 R, `rail_vias` R, `rail_traces` R. 사이트 차 ΔR_el = R_el(S1) − R_el(S0). 기여율 = ΔR_el / Σ_el ΔR_el.
- extract 통계(exp5 pkl): trace 수, "폭 없음"(width None) trace 수와 그 길이 합, via 수, 포트 양극 노드 수, 레일 노드 수, 포트 노드의 층 분포, 기준면 층 목록.
- 사이트 대칭 검사(기하): SITE0 포트 노드 좌표를 패키지 중심 대칭(x → −x 또는 y → −y, 두 축 각각 시도)으로 접었을 때 SITE1 포트 노드와의 최근접 거리 중앙값.

## 2. 가설(동결)
- H_tr: 상위 쌍에서 ΔR 기여율의 최대 요소가 `rail_traces`이고 기여율 ≥ 0.5인 쌍이 과반 → "trace(기본폭 포함) 경로가 사이트 차이의 주원인" 채택. 최대 요소가 `rail_vias`이면 "via 경로", 평면이면 "평면/기준면 검색"으로 분류.
- H_w: 폭 없는 trace 길이 합이 사이트 간 2배 이상 다른 쌍이 상위 8쌍 중 ≥ 5 → "기본폭 대입이 비대칭의 원인 후보" 채택.
- H_geo: 접힘 대칭 최근접 거리 중앙값이 포트 노드 간격(수백 µm)보다 작으면 두 사이트의 포트 정의는 기하적으로 대칭이다(추출 자체는 대칭). 크면 포트 정의가 다르다.

## 3. 판정 후 해석(미리 적음)
- H_tr(trace)·H_w 채택이면 다음 실험은 "폭 없는 trace의 폭을 SPD 원본(`.Trace` 기록 또는 층 기본폭)에서 다시 읽는 추출 수정"이며, 이는 규칙 변경이므로 플래그로 넣고 7케이스 + 어긋난 쌍에 대해 사전 등록 후 실행한다.
- via 경로가 원인이면 포트 노드 스냅·via 경로 선택 규칙을 조사한다.
