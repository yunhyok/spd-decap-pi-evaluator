# EXP-37 계획 — 효율: GPU 인수분해 이후 남은 병목(assemble·build) 가속 (물리 변경 없음)

작성 2026-09-17, 실행 전 사전 등록. §6-7(속도)의 대체 과제. EXP-36 92포트 GPU 실행에서 인수분해는 사라졌고(N 1.33M 포트: 인수분해 합 104 s / 벽시계 951 s), 남은 시간은 주파수당 `Model3.assemble()`(P18 약 3 s × 28점)과 모델 build(P18 475 s, N 1.3M 포트 약 35 분)다.

## 1. 규칙(고정)
- 물리·수치 정의를 바꾸지 않는다. 목표는 같은 입력에서 같은 Y(f)와 같은 Z(f)를 더 빨리 만드는 것뿐이다.
- 기본 경로(splu, 기존 assemble)는 바이트 단위로 불변. 가속은 옵트인(환경변수)으로 붙인다.
- 프로파일 → 상위 항목만 고친다(YAGNI). 캐시는 주파수 무관 부분(인덱스 맵, COO→CSC 위치 매핑, 상수 기하량)에 한정한다.

## 2. 판정 기준(동결)
- (a) 정확도: 7케이스 기준선 exp28/p 영수증 대비, 가속 경로(GPU 인수분해 포함)의 전 주파수 max |ΔZ|/|Z| ≤ 1e-8. 부동소수 합산 순서 차이만 허용.
- (b) 속도: P18 주파수당 assemble 3 s → ≤ 1 s, 포트 전체 벽시계(GPU) 2배 이상 단축이면 채택. build 가속은 별도 항목으로 프로파일 결과와 함께 보고만 하고, 구현은 상위 1–2개 함수에 한정한다.
- (c) 기본 경로 불변: `smoke_port18.py` PASS(5.83e-12), `run11.py --variant p --smoke --smoke-baseline exp28:p` 0.0.
