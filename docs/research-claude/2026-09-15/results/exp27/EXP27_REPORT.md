## 2. 결함 기구(P65 C10105_1, P29 C10030_0 추적)
- 패드 링크는 정상이다(Node755 ↔ TOP via 노드 ±50 µm 연결됨). 고립 성분은 33노드(패드 링크 2, via 18, trace 12, L10 시트 엣지 17)로, TOP → DR-0102 → … → DR-0910 → **L10 레일 시트**까지 이어진 뒤 끊긴다.
- L10 레일 artwork는 790 × 730 µm 폴리곤 하나이며, 고립 노드와 DR-1011_60 하향 via를 가진 이웃 노드(약 600 µm 거리)가 **같은 폴리곤 안**에 있다. 즉 물리적으로 연결돼 있다.
- 래스터 시트에서는 이 폴리곤이 65개 패치로 부서져 있다(L10 시트 127셀 / 74엣지). 폴리곤 내부 3 × 3 셀(fill 1.0)과 테두리 셀(fill 0.12–0.60) 사이의 **모든 엣지가 G = 0**이다. 원인은 `homog.batched_gx`의 경계조건: 창(cell centre → centre)의 양 끝 열(셀 중심선)에서 전류를 주입·인출하는데, 구리 경계가 두 셀 중심선 사이에 놓이면 테두리 셀의 중심선에는 금속이 없어(face fill 0) 주입 전류가 0 → I = 0 → G = 0(1e-6 문턱과 무관, 정확히 0). 창 자체의 fill은 0.32–0.90으로 금속이 충분하다.
- 그 결과 decap의 via 스택은 내부 패치에, 하향 via는 테두리 패치에 떨어져 갈바닉으로 끊긴다. 56개 고립이 모두 같은 기구로 보인다(폴리곤 가장자리에 걸린 셀).

## 3. 의미
- 이것은 추출 문제가 아니라 **균질화 경계조건의 산술적 결함**이며, decap 고립뿐 아니라 모든 평면의 가장자리 셀 연결(평면 R·L)에도 영향을 준다. R 오차와의 강한 상관(p 1e-6), 사이트 부호 반전(EXP-24), 4-decap 레일의 나머지 항 3배(EXP-25/26)를 한 번에 설명한다.
- 수정은 규칙 변경이므로 플래그(`homog_face_fix`)로 넣고 EXP-28에서 7케이스·연결성·92포트로 판정한다. 기본값·기준선은 그때까지 불변.
