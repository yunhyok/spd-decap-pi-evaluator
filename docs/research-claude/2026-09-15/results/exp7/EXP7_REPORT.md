## 1. 커널 해석해 검증 (L25 파라미터: d=100 µm, t=32 µm)

- 모델의 평면 edge는 R과 L이 같은 2-D 라플라시안을 공유한다: `Z = (Zs + jωμ0d)·N_sq`.
- 따라서 두 via 사이 저주파 해는 R = R□·N_sq, L = μ0d·N_sq이고, 무한 평면에서 N_sq = ln(s²/(r1r2))/(2π)다.
  - 2-D에서 원판 두 개 사이 확산저항 R = (R□/2π)·ln(s²/(r1r2))를 사용했다.
- 격자: 16×16 mm, 개방 경계, +1/−1 A 주입.
- 접촉 방식 두 가지를 비교했다.
  - node: via = 셀 노드 1개(EXP-3/5 모델의 관례)
  - disc: 반경 r 안 노드를 모두 short
- 5점 라플라시안의 점원 등가반경은 r_eq = h·e^(−π/2) ≈ 0.208h다.

**판정 (i): 커널은 옳다.**
- 해석 식과 1–8% 안에서 일치한다(격자 분산).
- 단, via 접촉을 노드 하나로 두므로 **유효 접촉반경이 물리 반경 r이 아니라 0.21h다.** 접촉 하나당 초과량은 ΔN = ln(r/0.21h)/(2π)다.
  - fine 박스(h=50)의 microvia(r=20 µm): **+0.10 □** (과대)
  - 같은 곳의 PTH(r=75 µm): **+0.31 □** (과대)
  - coarse(h=200)의 PTH: −0.09 □ (과소)
- 이 접촉들은 수백 개가 병렬이다. EXP-3 S4에서 fine 박스를 50→25 µm로 줄였을 때 Z가 0.55%만 변했으므로, 포트 전체에 대한 영향은 작다.

## 4. 판정

**(ii) 단일 h가 R과 L을 함께 닫는가? → 아니다. 가설은 기각이다.**
- port18: ΔL은 0.25–5 mm에서 +9.4~+15.7 pH로 **비단조**로 흔들릴 뿐 0에 다가가지 않는다. ΔRe는 +0.05 → −0.02 mΩ로 조금 움직이지만 ΔL과 같은 h에서 0이 되지 않는다.
- port1: 거칠게 할수록 ΔL(+94 → +181 pH)과 ΔRe(+0.02 → +0.55 mΩ)가 **모두 반대 방향으로 커진다.**
- 따라서 "mesh가 핀필드 스케일을 해상하지 못해 확산 L과 R이 함께 줄어든다"는 기제를 우리 커널로 모사하면 예측된 서명(ΔL·ΔRe 동시 0 교차)이 **나오지 않는다.**
- 이유[추정]: 이 레일의 평면 L은 DUT–decap 사이(수십 mm)의 분포 확산이 지배한다. 접촉 반경 항 ln(r)의 가중은 작고, 거친 격자는 오히려 형상(TOP·trace·섬)의 연결을 망가뜨린다.

**(iii) 사용자에게 요청할 PowerSI 실행** — 이 모델만으로는 가를 수 없으므로 참조 쪽 수렴을 직접 확인한다.
- 요청 내용: 260729를 **`.PowerSI MaxEdgeLength` = 1 mm, 0.5 mm로 재해석**(나머지 설정 동일)하고, port18 Z(f)를 Touchstone으로 export한다. 가능하면 0.25 mm 또는 via 주변 국소 세분화도 포함한다.
- **가설 H1 (PowerSI 4.97 mm mesh가 확산 L/R을 과소평가):**
  - mesh를 세분하면 PowerSI의 0.03–1 MHz L이 **+10~13 pH 증가**하고, Re가 **+0.03~0.1 mΩ 증가**한다.
  - 직렬공진은 1.585 → **약 1.3 MHz로 하강**(우리 모델 1.27 MHz 쪽)한다.
  - port1은 L이 수십 pH 증가(ΔL 약 0.3·L_plane)한다.
- **가설 H2 (PowerSI는 이미 수렴, 우리 평면쌍 L 공식이 약 30% 과대):**
  - PowerSI Z 변화가 1 MHz에서 **< 1–2 pH, < 0.01 mΩ, f_res 변화 < 2%**다.
- 이 두 파일이면 초과 L의 소재(참조 mesh 관례인지, 우리 공식인지)가 확정된다. 결과가 H2이면 다음 단계는 평면쌍 L의 3-D 보정(유한 폭·양측 귀환 분포)이다.
