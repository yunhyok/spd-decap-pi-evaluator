# EXP-34 계획 — G4 f_res 항의 대체 지표 판정: min|Z| f_res vs Im Z 영교차 f0 (자료만, 모델 실행 없음)

작성 2026-09-17, 실행 전 사전 등록. 소유자 위임(2026-09-17): 정확도·효율에 유리한 방향으로 게이트 지표를 결정. EXP-33에서 C·L은 맞는데 f_res(min|Z|)가 두 설계 모두 +10 % 편향 → 지표 조건 불량 재확인. D6에서 f0를 병행 지표로 두었으나 채택 여부는 미정이었다.

## 1. 정의(동결)
- 입력: 260729 exp28/p(92), exp32/q(92), s5m6585 exp30/p(160) 영수증. 참조는 826/626점 전체 grid, 모델은 사다리(0.3–30 MHz dense 21점 포함).
- f_res: 영수증 값(1–10 MHz min|Z|, 모델은 사다리 최근접). f0: Im Z가 음→양으로 처음 바뀌는 주파수(0.3–30 MHz 안, log-주파수 선형 보간; 모델은 사다리 점 사이 보간). 각 포트에서 r_fres = f_res,mod/f_res,ref, r_f0 = f0,mod/f0,ref.
- 조건성 검사: 예측치 r_pred = (r_L·r_C)^−1/2 (EXP-33 정의, 100 kHz C·10 MHz L; L 평가는 f0 위 최근접 사다리점으로 하되 f_res_ref < 5 MHz 조건은 "f0_ref < 15 MHz"로 완화 — 이번 실험 정의). 지표 X의 조건성 = |r_X − r_pred| ≤ 0.1인 포트 비율.
- 존재율: f0가 모델·참조 모두에서 정의되는 포트 비율.

## 2. 판정 기준(동결)
- **f0 채택**(G4의 f_res 항을 f0 ±10 %로 대체, D8로 기록): 세 집합 모두에서 f0 존재율 ≥ 0.8 이고 f0의 조건성이 f_res의 조건성보다 높다(비율 차 ≥ 0.1). 그 외는 현행 유지하고 결과만 기록.
- 채택 시 G4 = "1–10 MHz 최대 상대오차 < 20 % 그리고 f0 ±10 %"로 재정의하고, 92포트(p, q)·160포트(p)의 G4 PASS 수를 새 정의로 다시 보고한다. 과거 영수증은 재계산만 하고 파일은 덮어쓰지 않는다.
