# EXP-22 계획 — 유효 L의 주파수 의존: 참조와 모델 분해 (92포트 자료만, 모델 실행 없음)

작성 2026-09-17, 실행 전 사전 등록. EXP-19 H1′에서 D′ = ΔL_HF′ − ΔL_LF 중앙값 +135 pH가 나왔다. 이것이 "참조 L이 주파수에 따라 감소"인지 "모델 L이 증가"인지, 또 decap 모델(양쪽 공통 SPICE) 때문인지를 자료만으로 분해한다. 파라미터 변경 없음.

## 1. 정의(동결)
- 유효 L: L_eff(f) = Im Z(f)/(2πf). 참조 L_ref(f), 모델 L_mod(f)(exp15/j 영수증). 대상 주파수: f1 = max(2·f_res_ref, 5 MHz)에 가장 가까운 사다리 점, f2 = 30 MHz 최근접 점.
- 비율 ρ_ref = L_ref(f2)/L_ref(f1), ρ_mod = L_mod(f2)/L_mod(f1). 대상 포트: f_res_ref ≤ 5 MHz이고 L_ref(f1) > 0, L_mod(f1) > 0인 포트.
- 분해: D′ ≈ [L_mod(f2) − L_mod(f1)] − [L_ref(f2) − L_ref(f1)] = ΔL_mod − ΔL_ref.

## 2. 가설(동결)
- H_r(참조 L 감소): 대상 포트의 ρ_ref 중앙값 < 0.9이고 ρ_ref < 1인 비율 ≥ 0.7 → 채택. 중앙값 ≥ 0.97 → 기각.
- H_m(모델 L 일정): ρ_mod 중앙값이 0.97–1.03 안이면 채택(모델 L은 대역에서 사실상 일정). 밖이면 기각.
- H_dec(decap 기원): 양쪽에 같은 decap SPICE 모델이 들어가므로 decap 항은 D′에 기여하지 않는다는 가정을 검증한다 — 포트별 ΔL_ref와 decap 수(extract)의 Spearman |ρ| < 0.3이면 채택(decap 수와 무관), ≥ 0.5면 기각.
- 예측: H_r 채택, H_m 채택. 즉 차이는 참조 쪽 L 감소이며 모델은 표피효과 밖의 L 감소 기구(핀필드 via 간 근접효과, 평면 귀환 전류 집중)를 갖고 있지 않다.

## 3. 판정 후 해석(미리 적음)
- H_r·H_m 채택이면 §6-6 다음 정식화 후보는 "via 배열의 근접효과(인접 via 간 상호 L의 주파수 의존)"이며, 자유 계수 없는 폐형식이 있는지(Kim–Ren–Fan 등) 먼저 문헌을 확인한 뒤 등록한다.
- H_r 기각이면 D′의 원인은 반공진 근처의 지표 불안정으로 보고 ΔL 지표를 폐기한다.
