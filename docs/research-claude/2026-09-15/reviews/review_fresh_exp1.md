# EXP-1/1b/2 독립 물리 리뷰 (2026-09-15)

표기: [문서] = 보고서·코드·인용 출처에 있는 사실, [추론] = 필자 계산·판단, [미검증] = 확인 못 함.
스택업 수치는 `extract_port18.pkl` 파싱 결과에서 직접 읽었다 [문서]. L13/L14/L15/L16은 Cu 20 µm이고 ABF 간격이 각 30 µm(εr 3.4 @1 MHz)이다. L24/L25/L26/L27은 Cu 32 µm이고 간격이 100/105/100 µm(εr 4.7)이다. L14→L16은 80 µm, L25→L27은 237 µm다. 보고서의 d 값과 일치한다.

## 가장 중요한 관찰: 데이터가 이미 답의 절반을 준다

`result_exp1b.json`의 ΔIm/ω(모델−참조)는 주파수에 따라 크게 줄어든다 [문서].

| 주파수 | ΔIm/ω |
|---|---|
| 0.1–0.5 MHz | +23 pH |
| 1 MHz | +18 pH |
| 3–5 MHz | +9–10 pH |
| 15–100 MHz | +5–7 pH |

ΔRe는 1–100 kHz에서 +0.03 mΩ이고, 약 2 MHz에서 +0.14 mΩ로 정점을 찍은 뒤 고주파에서 +0.10 mΩ이다 [문서].

직렬 L이 일정하게 초과한다면 ΔL은 모든 주파수에서 같고 ΔRe는 0이어야 한다. 관측은 그렇지 않다. 따라서 이 오차는 **병렬 경로(L14 저L·고R / L25 고L·저R) 사이의 전류 분배 오류**라는 신호다 [추론]. 병렬 경로의 저주파 유효 L은 L_eff = R_eq²·Σ L_k/R_k²로, 저항 분배에 의존한다(표준 회로 해석).

→ 따라서 0.1–1 MHz의 ΔIm/ω를 "L"로 부르는 것은 부적절하다. 게이트는 둘로 나누기를 권한다.
- **분배 지표**: 0.1–1 MHz
- **직렬 L 지표**: ≥5 MHz, 전류 분배가 L로 결정되는 영역

Track A가 L(f) 부호 반전을 "분포 특성"으로 해석한 것은 틀렸다. 이는 공진 근처에서 고정 C_eff를 빼면서 생긴 인공물이다. 1.6 MHz 파장은 약 86 m(εr 4.7)로 패키지보다 훨씬 커서 집중정수 영역이다. Q≈0.41도 R이 지배한다는 뜻이다 [추론].

## Q1. EXP-1c(이웃 타넷 전원면을 귀환면으로 취급)는 정당한가? → **아니다.** 단, 코디네이터의 근거 중 하나는 L26에 대해 틀렸다.

**면당 차폐비** α = jωμ0d₂/(R□ + jωμ0d₂) [추론, 두 도체 변압기 등가]:
- **L15**: R□ = 1/(5.959e7·20 µm) = 0.84 mΩ/□, ωμ0·30 µm = 0.24 mΩ/□ (1 MHz) → |α| ≈ 0.27. 약한 차폐이며, 코디네이터 논리가 맞다.
- **L26**: R□ = 0.52 mΩ/□, ωμ0·100 µm = 0.79 mΩ/□ → **|α| ≈ 0.83**. 면당 기준으로는 강한 차폐다. "1.2 vs 0.2 mΩ/□"는 이 스택 수치가 아니다.

**그래도 투명에 가까운 이유** [추론]:
1. **위상 제약**: 떠 있는 판의 유도전류는 발산이 0(solenoidal)이어야 한다. 레일 L25 전류는 DUT 비아(소스)에서 디캡 비아(싱크)로 넓은 판을 흐르는 퍼텐셜 흐름이라 대부분 irrotational이다. Helmholtz 분해에서 두 성분은 직교하므로, 떠 있는 L26이 거울 전류로 상쇄할 수 있는 몫은 작다.
2. **갈바닉/용량 폐로의 임피던스가 너무 크다**:
   - L26의 판간 C는 0.40+0.42 ≈ 0.8 pF/mm²다. DUT 창(~200 mm²)에서 약 160 pF → 1 MHz에서 약 1 kΩ, 판 전체(수천 mm² [미검증])라도 약 2 nF → 약 80 Ω이다.
   - 이득은 ω·14 pH ≈ 0.09 mΩ에 불과해 폐로 임피던스보다 10⁶배 이상 작다.
   - DUT 쪽 ADC_VDD_055 핀은 Z 추출에서 open(타 포트 개방)이다. 그 넷 디캡은 DUT에서 멀다 [미검증: 위치 미확인].
   - Ott도 전원면이 귀환면이 되려면 디캡이 경로를 이어야 하고, 판간 C는 "considerably above 500 MHz"에서만 효과가 있다고 쓴다 [문서] https://hott.shielddigitaldesign.com/techtips/pcb-stack-up-6.html
3. **방향이 반대다**:
   - 거울 전류가 생기면 L은 줄지만 R이 늘어난다. L26 하부 간격 항이 j0.79 → 0.37+j0.25 mΩ/□가 된다. 그런데 모델 Re는 이미 1 MHz에서 +0.07 mΩ 높다.
   - 무엇보다 떠 있는 판 효과는 ω에 비례해 **주파수와 함께 커진다**(10 kHz에서 |α| ≈ 0.015). 필요한 보정은 저주파에서 크고(23 pH) 고주파에서 작다(5–7 pH).
   - 정적 d_eff로 −14 pH를 빼면 고주파는 −7 pH로 과보정되고, 저주파는 여전히 +9 pH 남는다. **데이터 형태가 EXP-1c를 기각한다.**
4. EXP-2에서 떠 있는 L15/L26의 기여는 0.002–0.004 mΩ로 미미했다 [문서]. EXP-2 공식 자체가 ill-posed였으므로 보조 근거로만 쓴다.

## Q2. 과잉 ~15–25 pH 가설 순위

**1위 (H-A): 좁은 도체폭 영역에서 2-D 변 L 과대평가 (fringing 무시)**
- 셀 변 L = μ0·d/□은 폭 ≫ d일 때만 정확하다.
- DUT 아래 L14의 100 µm 줄무늬(d 22–30 µm)는 폭/d가 3–5다. L25 핀필드의 anti-pad 사이 web은 d_eff 70–100 µm에 대해 폭이 수백 µm로 추정된다 [미검증: web 폭 미측정].
- 실제 L은 대략 μ0·d·ℓ/(w+2d)로 1.4–1.7배 낮다 [추론]. **같은 코드가 trace에는 w+2d를 쓰고 평면 raster에는 쓰지 않는다** [문서: model.py:347 vs 512] — 불일치다.
- 이 오차는 L형이다. 저주파에서는 L25 전류 몫이 커서 크게 보이고, 고주파에서 작아진다. 관측 형태와 맞는다.

**2위 (H-B): 전류 분배 R 오류 — G1 PASS는 상쇄 오차일 가능성**
- PowerSI plane solver는 "metal/dielectric losses"를 포함한다 [문서: Cadence forum 57376]. GND 저항이 0일 리 없다.
- 이상 GND가 R을 0.03 mΩ로 맞춘 것은 레일 쪽 R이 GND R만큼(~0.2 mΩ, EXP-2 +0.23 [문서]) **과대**라는 뜻일 수 있다 [추론]. 후보는 DUT 아래 L14의 50 µm 4-이웃 raster 톱니, hex 영역(도형 없음, trace만), via R 추정이다.
- L14가 과저항이면 저주파에서 전류가 L25(고L)로 우회해 ΔL이 커진다. 고주파에는 L14로 강제되어 ΔRe가 양수가 된다. 관측 2 MHz bump와 맞는다.
- H-A도 bump를 일부 만들므로 결정적 차이는 **저주파 Re 절대값의 향방**이다(Q3).

**3위 — via**: 978개 동축 L을 상호 L 없이 병렬로 처리하면 배열 L이 **과소**평가된다(Kim-Ren-Fan 2010 [문서]). 보정하면 초과가 커지므로 원인이 아니다. 대신 H-A/H-B 보정량을 약간 키운다.

**배제한 가설**
- **내부 L**: 단면 coth Zs(μ0t/3)를 양측 귀환에 쓰면 레일 내부 L을 과대계상한다(L14 ≈ μ0·3.9 µm, L25 ≈ μ0·6.7 µm, 합 ~4–5 pH). 그러나 이상 GND가 뺀 GND 내부 L(L13 ≈ μ0·3.6 µm, L24+L27 ≈ μ0·6.2 µm)과 거의 상쇄된다 → 순효과 ≈0 [추론]. "하한"은 근사적으로만 성립한다.
- **(d) 포트**: 978핀 초노드는 L을 낮춘다. PowerSI가 이보다 낮을 수 없다.
- **(b) 스택업**: 수치 검증 완료, 1 kHz C도 13 ppm 일치.
- **(e) 전체 GND 스택/타넷 경로**: 이상 귀환 하한 아래로 내려갈 수 없다.
- **(g) DUT 범프 L**: 참조 L을 올릴 뿐이다.
- **(f) 이중계상**: μ0d/□은 h와 무관하게 옳다(폭 ≫ d일 때). 평면 위 trace 중복은 병렬이라 L을 낮출 뿐 직렬 이중계상이 아니다.

## Q3. 판별 실험 1개: "영역 분할 breakdown + 2노브 민감도"

- **주파수**: 10k, 100k, 300k, 1M, 3M, 10M, 30M Hz
- **run 수**: 3 × 7 × ~2.5 s ≈ 1분
- **Run 0**: 1b 그대로 두고 `loss_breakdown`을 fine box 안/밖으로 분할한다. L25의 25–38 pH가 **box 밖 solid 구간**에 대부분 있으면 H-A(L25 부분)는 약화된다(solid 판에서 2-D는 정확).
- **Run L (H-A 노브)**: fine box 안 L14/L25 평면 변의 jωμ0d에만 0.65를 곱한다(R 불변).
- **Run R (H-B 노브)**: fine box 안 L14 평면 변과 box 내 trace의 R에만 0.7을 곱한다(L 불변).

| 관측 | H-A가 참이면 | H-B가 참이면 |
|---|---|---|
| Run L: 0.1–1 MHz ΔL | ≤±5 pH로 수렴, 고주파 ΔL → ~0 | 거의 균일 감소, 2 MHz ΔRe bump 잔존 |
| Run L: 저주파 ΔRe | 불변(+0.03) | 불변 |
| Run R: 0.1–1 MHz ΔL | 변화 <5 pH | **≥10 pH 감소**, 고주파 ΔL 변화 <2 pH |
| Run R: 저주파 ΔRe | −0.05~−0.1 mΩ (G1 FAIL, 설명 불가) | −0.1 mΩ — PowerSI GND R가 채울 틈으로 해석 가능 (EXP-2 +0.23과 정합) |

판정: Run R이 저주파 ΔL을 크게 줄이면 H-B, Run L만 줄이면 H-A다. 둘 다 부분이면 fringing 보정과 명시 GND R(단순 균일 시트 R)을 결합한 후속 실험으로 간다.

**260729 vs 260804 ΔZ**

  - 기저 오차(16 %)가 델타 크기(1 MHz 14 %)와 같다.
  - 디캡 293개 감소와 유전체 재질·두께 변경(상부 15 µm [문서: DATA_CHARACTERIZATION])이 뒤섞여 원인 분리가 안 된다.
