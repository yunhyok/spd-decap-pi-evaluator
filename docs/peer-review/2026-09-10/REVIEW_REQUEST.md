# 외부 Peer Review 검토 요청서

대상: **SPD Decap PI Evaluator v0.23.1**, 2026-09-10 정지 시점의 연구 구현 및 [독립 재검토 보고서](REPORT.md).

## 목적과 제공 자료

SPD로부터 복소 임피던스를 계산하여 **1kHz–100MHz**에서 PowerSI와 비슷한 정확도를 가진 빠른 pre-design PI 도구를 만들고자 한다. 현 단계는 목표 정확도에 도달하지 못했다. 국소 수치 문제에 매몰되어 전체 모델 확립이 지연되는지, 현재 연구 방향을 유지할 근거가 있는지 외부의 독립 판단을 요청한다.

정확한 공통 물리 모델을 우선한다. 512GB RAM·Threadripper·가능한 GPU 활용은 계산 수단이다. 임의 계수로 참조 결과에 맞추거나, 자원 절약을 이유로 동일 도체의 물리 표현을 근거 없이 바꾸는 접근은 목표가 아니다. 목표 허용 오차와 실행시간의 수치 계약도 심사에서 제안해 주기 바란다.

[보고서](REPORT.md), [근거·실행 소스](EVIDENCE.md), [대형 데이터와 제공 범위](DATA.md), [원본 해시 및 경로 대응](manifest.json)을 제공한다. 원문과 보존된 실패 결과를 포함했다. GitHub의 게시 commit SHA를 검토서에 기록해 검토 대상을 고정해 주기 바란다.

## 우선 검토 질문

1. **물리 문제의 정의:** 현재 조건부 A는 어떤 경계값 문제를 근사하는가? 전원·귀환·비아·유전체·포트의 누락과 중복, 항별 소유가 충분히 정의되어 있는가?
2. **오차와 판정:** 같은 A의 수치 오차, 메시·구적 오차, 모델 오차, 참조 조건 차이를 어떻게 분리할 것인가? `|J−Z|`와 전체 residual의 한계를 고려한 포트 오차 예산은 무엇인가?
3. **최근 개선의 의미:** 같은 시작점·같은 A에서 M만 바꾼 세 실험은 무엇을 입증하며, 무엇을 입증하지 못하는가? 다음 보조행렬 변경에 앞서 어떤 최소 증거가 필요한가?
4. **공간 표현과 adaptive mesh:** 현재 sheet 전류·전하 공간, 두께 근사, 자기 kernel 및 near 구적은 주대역에 적절한가? 형상 기반 세분화와 해 기반 적응을 어떻게 검증하고, 어떤 포트 기준으로 종료할 것인가?
5. **대안과 연구 순서:** 현재 A의 수치 재설계, 일관된 current/charge 모델, 유한 도전율 경계법, 안정화 FEM 중 어떤 한 대조가 가장 빨리 원인을 가를 수 있는가? 선택의 가정과 기각 조건을 제시해 주기 바란다.
6. **제품 목표:** 정확도와 전체 계산시간을 어떤 대표 보드·포트·설계 변경으로 판단해야 하는가? 워크스테이션/GPU가 해결할 계산 비용과 별도로 남는 모델 문제를 구분해 주기 바란다.

## 요청하는 검토 결과 형식

아래 형식으로 Markdown 또는 문서 파일을 작성해 주기 바란다. 저장소 내 별도 검토 문서/PR로 남기거나, 사용자가 사용하는 외부 검토 채널에서 같은 commit을 참조하면 된다. 이 요청서는 검토자에게 자동 발송된 것이 아니다.

```text
검토자 / 검토일 / 검토한 commit SHA:
총평: 현 경로 유지 / 수정 후 유지 / 대안으로 전환 / 근거 부족

질문 번호와 우선순위:
판정: 동의 / 수정 / 반대 / 판단 불가
근거: 보고서 절, 파일 링크·행, 식 또는 문헌
현재 근거로 확정할 수 있는 내용:
아직 확정할 수 없는 내용:
가장 작은 판별 실험 또는 반증 조건:
연구 재개에 필요한 증거:

권고하는 다음 한 단계:
지금 보류할 작업:
추가로 필요한 원본 데이터·설정(있을 때):
```

검토 문서와 데이터의 게시 승인은 계산 재개 승인이 아니다. 현재 solver·구현·자동 후속 연구는 중지되어 있으며, 검토 결과를 바탕으로 사용자가 다음 단계를 결정한다.
