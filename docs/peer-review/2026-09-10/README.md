Fable의 원인 중심 재정렬은 채택하되, 미수렴 값으로 물리 원인을 확정하거나 성능·기간을 보장하는 주장은 채택하지 않았다. 기존 승인 정책의 적용 범위와 새 목표 초안도 구분했다. 이 후속 검토는 계산 재개 또는 정확도 개선 완료를 뜻하지 않는다.

주 관심 대역은 **1kHz–100MHz**이며, 정확한 공통 물리 모델을 우선한다. 1MHz의 26.18%와 최신 10MHz의 54.59%는 서로 다른 조건의 비교값이다. 최신 10MHz 계산은 미수렴이며 정확도 개선이 인정된 결과가 아니다. 심사의 목적은 현재 경로를 유지·수정·전환할 근거와 최소 판별 실험을 정하는 것이다.

위 GitHub 링크에서 문서와 Release 첨부 자료를 열 수 있다. 접근 범위는 저장소의 현재 GitHub 설정을 따른다. 검토 기준은 이 자료가 게시된 commit으로 고정하고, 저장소 최상위의 제품 소스보다 이 폴더의 `snapshots/hq/`와 실행 당시 `driver-at-run.py`를 우선 대조한다.

게시를 위해 링크·탐색 문서만 정리했으며, 원문·결과·소스 스냅샷의 바이트는 보존했다. 대형 배열은 게시 복사본의 SHA256을 새로 확인했다. 계산이나 물리 검증을 다시 수행한 것은 아니다. 연구와 자동 후속 작업은 중지 상태를 유지한다.

보존한 과거 입력 기록 중 `astra-native-loaded-vtrip-field-02/field.json`은 원본 자체가 유효한 JSON으로 해석되지 않는다. 수정 없이 보존하고 [manifest](manifest.json)의 `historical_json_parse_errors`에 표시했다. 최신 세 실험의 직접 인용 결과 JSON은 정상 해석되며 원래 해시와 일치한다.
